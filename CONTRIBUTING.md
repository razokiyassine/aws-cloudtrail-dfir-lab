# Contributing

This is a course-based educational repository. Before sending a change, please preserve the difference between:
1. native API request logs generated by LocalStack, and
2. synthetic CloudTrail-like events generated by the included Python script.

Run `python -m unittest discover -s tests -v` and `python scripts/verify_fixture.py` before requesting a change. Never include credentials or instructor-only corrections. For any code sourced from the original course, respect its redistribution requirements.
