# Contributing

This is an educational cloud-DFIR portfolio project.

1. Keep all examples limited to emulated or explicitly authorized environments.
2. Document reproducible behavior, expected output and limitations.
3. Add regression tests for detection-rule changes.
4. Preserve the distinction between native LocalStack requests and synthetic CloudTrail-like records.
5. Never commit credentials, proprietary academic corrections or third-party material without redistribution permission.
6. Use clear pull-request descriptions and explain changes to alert severity or false-positive rates.
